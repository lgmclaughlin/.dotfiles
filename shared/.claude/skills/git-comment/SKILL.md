## Summarize the current Git Diff for a commit message

### Steps

1. Look at the full git diff for context. If none, then check the diffs of all added files.
2. Summarize all the main changes in the diffs with 2-5 words perpoint separated by commas. Do not include detail of very small changes, just the overarching ones so the commit message stays potent.
